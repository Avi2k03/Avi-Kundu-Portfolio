# Avi Kundu - Portfolio

## Folder structure
```
avi-portfolio/
├── index.html        <- all content (text, projects, skills, contact)
├── css/
│   └── style.css     <- colors, layout, fonts
├── js/
│   └── script.js     <- animated background + weather
├── assets/
│   └── avatar.jpg    <- your profile photo
└── README.md
```

## Run in VS Code
1. File > Open Folder > select `avi-portfolio`
2. Install the **Live Server** extension (Ritwick Dey)
3. Right-click `index.html` > **Open with Live Server**

(Or just double-click `index.html` to open it in a browser.)

## Common edits
- Text/projects/skills: `index.html`
- Colors: `:root { ... }` at the top of `css/style.css`
- Photo: replace `assets/avatar.jpg` (keep the same name)
- LinkedIn: search `LinkedIn` in `index.html` and replace `href="#"`
